# Survey Analytics · Steel Blue (dark) — Power BI theme

A Power BI report theme that matches the **Punjab Assembly 2027 · Survey Analytics** dashboard: a dark Steel Blue canvas,
frosted-glass cards with rounded corners, and the project's party colours.

## Files

| File | What it is |
|---|---|
| `Survey_Analytics_Steel_Blue_dark.json` | The theme, with the dashboard background built in as the page canvas. Use this one. |

The background image on its own is in `../Dashboard_background/` (1920×1080 PNG and JPG, 3840×2160 PNG).

## Apply the theme

1. Open the report in Power BI Desktop.
2. Go to **Design → Import Themes → Browse for themes**.
3. Select `Survey_Analytics_Steel_Blue_dark.json`.

The theme changes default formatting only. A visual that was formatted by hand keeps its own settings until you select
**Reset to default** in its format pane.

## What the theme sets

| Area | Setting |
|---|---|
| Page | The dashboard background, scaled to fill a 16:9 page; `#080C11` around the page |
| Visuals | Frosted card (white at 94% transparency), border `#2B3036`, 18 px rounded corners |
| Text | Segoe UI. Headline numbers white, 28 pt; titles `#E8ECF0`, 12 pt; labels `#C8D0D9`; axes and legends `#97A3B0` |
| Tables and matrices | Dark rows (`#171B1F` / `#12161B`), grey column headers, subtle gridlines |
| Slicers | Dark items, light text |
| Status colours | Good `#6EE7B7`, neutral `#FCD34D`, bad `#FCA5A5` |
| Accent | Steel blue `#6B9AC4` |
